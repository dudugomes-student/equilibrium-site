# Equilibrium Multi

Site multipágina estático para serviços médicos.

## Páginas

- `index.html`: página inicial e apresentação.
- `servicos.html`: serviços e frentes de atuação.
- `equipe.html`: posicionamento, valores e equipe.
- `contato.html`: canais de contato e formulário.
- `privacidade.html`: política de privacidade/LGPD.

## Executar localmente

Abra `index.html` no navegador ou use qualquer servidor estático local.

O botão de WhatsApp usa o número configurado nos links `wa.me` dentro dos arquivos HTML.
